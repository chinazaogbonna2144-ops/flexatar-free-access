# Free 30-minute animatic

This workflow renders an **illustrated animatic**, not a photorealistic AI-generated film. It uses original Pillow-drawn scene art, slow zoom movement, chapter captions, and synthesized ambient audio. It does not need paid APIs, API keys, or paid video credits.

## Run it from an Android phone

1. Open the repository: https://github.com/chinazaogbonna2144-ops/flexatar-free-access
2. Switch the branch selector from main to video-generator.
3. Open the Actions tab.
4. Select **Render Free 30-Minute Animatic**.
5. Tap **Run workflow**, keep the video-generator branch selected, and confirm.
6. When the run finishes, open that run and download the artifact named girl-who-heard-her-dead-mother-30min-animatic.

## What it creates

- the-girl-who-heard-her-dead-mother-30min-animatic.mp4
- scene-list.txt

The video has ten chapters, each three minutes long, with a synthesized suspense drone. The artwork is deliberately stylized. For a realistic full film with lifelike characters and spoken dialogue, separate free AI video/audio generation would be needed; GitHub Actions alone does not provide a hosted generative video model.

## Free-use notes

GitHub Actions usage is subject to GitHub's current plan limits and repository settings. The render can take a while because it produces a 30-minute video. No external secrets are required.
