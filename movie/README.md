# The Girl Who Heard Her Dead Mother
## 30-minute short film production workspace

This folder contains the screenplay, production plan, and shot list for a supernatural mystery short film.

**Target runtime:** 30 minutes  
**Genre:** Supernatural mystery / emotional drama  
**Format:** 16:9 cinematic master (can be reframed for vertical excerpts)  
**Workflow:** Generate short video shots, review and label each clip, then assemble in editing software. GitHub stores the creative materials and production tracking; it does not itself render or export a finished movie.

### Production files
- [Screenplay](screenplay.md)
- [Shot list and timeline](shot-list.md)
- [Production workflow](production-workflow.md)

### Important
A finished 30-minute AI film requires many generated clips, plus editing, dialogue/audio, music, and quality review. Video generation can cost credits. Do not start paid generation until the exact quote and settings are reviewed and approved. Keep generated media in a separate asset store or release folder rather than committing large MP4s to Git history.

### Suggested delivery
- 30:00 final runtime
- 1920×1080, 24 fps, H.264 MP4
- Stereo dialogue and sound design
- Captions/subtitles
- Credits and a final continuity review
